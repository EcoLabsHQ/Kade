The user's global custom `btw` implementation was removed on request:
`~/.config/opencode/agent/btw.md`, `~/.config/opencode/command/btw.md`,
`~/.config/opencode/plugin/btw.ts`, and the `opencode.jsonc` plugin entry.

not part of the repository and is not tracked here.

## Known limitations

- The 12 harness scenarios are documented as acceptance shape; only the
  worktree-isolation subset is mechanically exercised by a worker. The
  regression guard covers configuration invariants, not runtime orchestration.
- OpenCode-native worktrees are not used; the helper is the Git fallback
  permitted by `docs/orchestration.md` §6.
- Runtime orchestration state (`.orchestration/`) is git-ignored and was not
  persisted for this iteration; this report is the retained summary.
